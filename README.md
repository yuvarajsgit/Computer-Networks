# Network Layer Simulation in C

## About the Project

This project is a C program that simulates data transmission through different network layers.

It uses a hash table to store:

```text
URL → IP Address → MAC Address
```

## Features

* Read a message from a text file
* Display character, binary, and hexadecimal values
* URL, IP, and MAC address mapping
* Add, update, delete, and search URL entries
* Hash table using linear probing
* Generate random port numbers
* Convert IP and MAC addresses to binary
* Application Layer simulation
* Transport Layer simulation
* Network Layer simulation
* Data Link Layer simulation
* Create 16-bit packets
* Create 8-bit frames
* Display total packets and frames

## Files

## How to Run

Compile the program:

```bash
gcc main.c -o main
```

Run the program:

```bash
./main
```

Make sure `message.txt` is in the same folder as `main.c`.
